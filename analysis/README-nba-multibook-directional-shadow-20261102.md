# NBA独立影子｜多机构报价能否提高三玩法预测准确率（2026-11-02）

## 核心方向

只预测 **独赢、让分、大小分** 的方向及概率，分别结算竞彩3项和皇冠ID3两项；**不寻找差价、不计算下注收益、不从原模型读取预测、不读取当前比赛赛果**。

独立影子现状的致命短板：`nba_independent_market_shadow.py` 一直把007多机构盘口的中位数作为比分/净胜分预测，用固定分差与总分标准差推导五个方向。跨时间的同一机构盘口变动虽然曾存为特征，但并没有进入任何实际独立的数值候选预测，也未与真正21:30官方原模型同场同盘口对照独立建模。

**本次修改引入更好的独立候选，但并不宣称已经提高准确率；真实提升必须经未来冻结的21:30比赛复盘才能确认。**

## 从真实007档案中看到的信息

北京时间2026-11-03的15场NBA赛事，21:30快照各场约10家独立机构报价；对照12:00快照，共有**13场**至少拥有3家同时出现在两次实际采集中的相同机构可比较让分和大小分。

例：主场骑士对客场雷霆（007 `728298`），让分中位数由12:00的 **主让3.75** 升至21:30的 **主让4.5**（007存储的正值代表主队让分，和用户展示的`主-4.5`相反）。8家可配对机构中，3家进一步增加主让，5家不变，0家减少主让。因此“盘口整体更偏向骑士”成立，“8家机构一致升盘”则不成立。大小分中位数228.5基本不变，不能由让分升盘直接断言大分。

## 研究架构

1. 按**同一007比赛ID / 同一博彩公司ID / 每个独立采集时间**保留每份时序快照，最多18份历史输入。来源是当时已入库的原始007机构盘口快照；绝不将不同机构报价拼接成同一时间序列，也不把007观察时间冒充为博彩公司真实调盘时间。
2. 严格剔除上游拒收机构、重复机构ID、异常价格、已封盘/未验证盘口和未来时间戳。每家机构每个时间点只投一票；原始同盘口模式线与跨机构全样本中位数明确分开。
3. 构造方向特征：有多少机构上升/下降/不变、全部机构同向占比、变动机构同向占比、连续时间段是否反转、历史累计移动幅度、机构报价中位绝对偏差（MAD）等。不根据机构“名气”指定权重；不混淆00:00、12:00、18:00、21:30之间的时间来源。
4. **数值增强候选（只在影子模型内部并排冻结）**：跨公司等权稳健Huber截断中心值，结合机构分歧造成的*保守*不确定性膨胀，推导净胜分与总分分布；按**竞彩和皇冠各自真实让分与大小分线**得到五玩法方向及概率。中心价和机构差异比仅用盘口中位数更全面，但不是受历史赛果验证的加权提升。
5. 保留现有独立影子五玩法`markets`不变，候选写入`research_model_candidates.ROBUST_MULTIBOOK`，不改原模型概率、不修改PushPlus、不修改两系统21:30答卷的既有定义。影子评分程序**单独**输出三方同一比赛、同一盘口、同一21:30原始封存答卷的候选对照；不得把候选提升冒充影子主成绩。
6. 保留每份来源、独立机构变化特征、候选概率与代码哈希存档；封存程序验证候选`line`与`signed_home_handicap`严格不变。新候选没有同赛季赛果作为输入，也没有赔率差价训练目标。

## 学术研究对设计的支持和限制

- Gandar et al., 1998, *Journal of Finance*: NBA让分盘口从开盘到收盘的移动，通常有预测价值；但其意义是市场最新信息已纳入最新价格，**不应该把相同变化无依据地叠加在现价上再提高独赢概率**。DOI: 10.1111/0022-1082.155346
- Gandar, Zuber & Dare, 2000, *Journal of Sports Economics*: NBA总分盘口的收盘线通常比开盘线更好；但“大分市场上涨”不能说明任何新的高于当前盘口的大分概率必然更大。DOI: 10.1177/152700250000100205
- Simon, 2024, *Management Science*: 基于四家博彩公司、3,681场MLB市场的时间序列，发现赔率/盘口短期变动可能过度反应；该结论来自**棒球**，不能直接照搬到NBA，需要检验异动回撤/持续性。DOI: 10.1287/mnsc.2022.00456
- Štrumbelj, 2014, *International Journal of Forecasting*: 不同机构的隐含概率预测品质可能不同；但007原始水位方向没有全覆盖独立核验，**此阶段绝不把两侧水位强行映射成主队或大分概率**。DOI: 10.1016/j.ijforecast.2014.02.008

## 量化验收

- 同一天同一场独立比赛是一个样本，不是“10家公司×几次快照=50个独立样本”。
- **只有赛前21:30已经真实冻结、Git SHA256存档、对上官方完赛比分、同盘口且无走盘的成对观察**才计入准确率和Brier。
- 五玩法分别计算：原模型 vs 影子独立中位数基线 vs 机构稳健中心候选的**方向命中数、总数、Brier分数**。零样本显示`n=0`，不得冒充“模型提高”。
- 训练出机构可靠性动态权重、球队分差残差、盘路反转的拟合系数，必须等到未来足够多严格赛前时间锁的**真实独立比赛**；更广泛的23,574场只可辅助估计分差/总分先验，不能冒充23,574个多机构赛前时序样本。
- 原竞彩/皇冠五玩法推送仍由原模型负责，影子正式答卷和候选仅内部封存；当前影子候选所需额外CPU运算是纯Python等权统计，不增加007网络请求、PushPlus发送或Cloudflare调度。
