# NBA 历史回测 V1：时序隔离与概率校准

## 真实云端验收
- https://github.com/noki1022/mcp-sports-hub/actions/runs/40737974638
- Actions Artifacts：nba_chronological_backtest.json 和 nba_holdout_predictions.csv（逐场赛前预测及最晚特征来源日期）。
- 研究目标：预测比分、分差及固定阈值的概率；**不是**历史皇冠盘口 EV/ROI 回测。

## 固定样本划分

| 集合 | 时间范围 | 比赛数 | 用途 |
|---|---|---:|---|
| 训练 | 2022–23、2023–24 两季 | 2413 | 拟合标准化和系数 |
| 参数验证 | 2024-10-22 至 2025-01-31 | 706 | 岭回归候选惩罚系数选择 |
| 隔离/Embargo | 2025-02-01 至 02-07 | 55 | 不参与训练、选参、校准 |
| 校准 | 2025-02-08 至 04-13 | 464 | 估计训练模型预测均值偏差与残差标准差 |
| 保留测试 | 2025-10-21 至 2026-04-12 | 1225 | 模型参数冻结后一次性测试 |
| 2026–27 | 56 | 监测，不参与调参或评分 |

## 防泄漏机制

1. 逐天时间排序，**同一天全部比赛先构建特征，再写入当天结果**。
2. 最近五场、历史交锋的来源日期必须严格早于目标比赛日期，逐场 CSV 保存最晚来源日期以供审计。
3. 同场比赛只有主客球队比分互相一致才会入库；每场比赛只保留唯一主客配对。
4. 标准化只在训练集拟合；超参数只在验证集选择；校准偏差和高斯残差标准差只用隔离期之后的校准集拟合。
5. 独立测试集不参与拟合、选参、校准。所有模型预先固定为基准、近五场/效率、再加交锋三种版本。
6. 不能把当前伤停、最新赔率填回历史比赛；历史赔率缺失时不测 EV/ROI/赢利率。

## 独立测试结果

| 模型 | 分差 MAE | 总分 MAE | 主队胜率 Brier | 固定 225.5 大分 Brier |
|---|---:|---:|---:|---:|
| 历史均值 | 13.143 | 15.898 | 0.247897 | 0.241216 |
| 近五场+效率 | 12.149 | 15.499 | 0.223416 | 0.234931 |
| 再加交锋 | 11.999 | 15.408 | 0.220207 | 0.233639 |

Brier 越低越好。交锋数据贡献较小：
- 主胜概率 Brier 改善 -0.003209；按日聚类 bootstrap 95% 区间约 [-0.006023,-0.000748]。
- 固定 225.5 总分 Brier 改善 -0.001292；95% 区间约 [-0.003402,+0.001135]；含零，不足以认为稳定改善。
- 该区间未涵盖各种不同特征选择和研究者多重尝试带来的选择偏差。

## 不能做的推断

- 固定 225.5 总分线、-5.5/-0.5/5.5 分差线是研究阈值，**不是当年的 007 盘口**。
- 校准方式是独立样本上的残差均值和高斯方差估计，而非完整的概率可靠度再校准；需要后续检查分箱可靠度、校准斜率与截距。
- CSV 公开的完赛日期不等于历史上逐条记录的发布时间；虽然特征严格早于比赛日期，但无法证明每条在当时的公开可得性，未来需加入一到两日滞后敏感性分析。
- 只有一个独立测试赛季。未来应预先设计多折滚动前向验证，并留出新的真正未见赛季。**已看过 2025–26 结果后不可反复在该赛季调参还称其独立测试。**
- 球队每百回合效率使用近似回合数，未完整处理加时、对手强度及历史伤停。
- 没有历史赛前带时间戳的皇冠盘口/水位、真实可成交报价和盘口变化，因此**没有真实历史价值差、EV、ROI 或盈利率结论**。
- 仅供研究；全部标记 NO_BET，不自动下注。

## 复现方法

进入 GitHub Actions 手动执行工作流 NBA chronological anti-leakage backtest acceptance。输出同时包含历史来源 SHA256、样本划分、训练系数、校准参数、概率指标、日聚类 bootstrap 和每场赛前预测。
