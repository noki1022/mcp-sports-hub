# NBA 模型最高分析纪律｜赔率不是结论

> **“如果光看竞彩赔率那个低就能命中，那世界上没有穷人。”**

这是 NBA 模型分析、21:30/06:30 重点排序、每小时复盘及改进实验的固定约束，不是自动调整赔率的启发式。

1. **独立预测先行。** 模型胜率、主客得分均值与净胜分只能由赛前可获得且经验证的比赛特征和历史训练/校准确定。竞彩赔率和皇冠水位不是独立胜率模型的输入；不因低赔率、名气或公众倾向改动预测。
2. **模型排序不参照赔率。** 重点关注采用模型自身概率及赛前数据质量排序。任何市场报价变化均不得使某场被插入、替换、提级或降级。
3. **市场比较仅为事后独立诊断。** 先冻结预测和重点名单，再检查同一盘口、同一来源时刻的竞彩/皇冠报价，分别显示去水市场隐含概率、独立模型概率、差值和盘口变化。极端相反值得关注，不是自动的正期望。
4. **不隐藏逆向信号。** 比如主胜 1.44，而独立模型主胜 9.9%，应同时保留原始预测、市场报价及巨大分歧。不因为市场一致性不足而删去模型结果；模型无效或赛前证据缺失时必须明确列出质量问题。
5. **校准故障与逆向结论分开。** 数据来源、主客映射、未来信息泄漏、0/100% 端点、校准样本支持、伤停证据都需要独立校验。不能把模型犯错冒充为聪明的逆向判断，也不能仅因不合赔率就认定模型犯错。
6. **不添加情绪主观成分。** 禁止“稳赢、稳胆、庄家诱盘、必出”等无可验证依据的表述。没有必要凑满重点场次、五玩法中的不可用报价不得伪装为可用预测。
7. **按真实结果检验。** 使用赛前已冻结的概率、盘口、时间戳和最终官方比分，分别评估概率 Brier/log loss、分差/总分误差、五玩法命中率、逆向分歧组与市场一致组；记录样本数和不确定性，任何参数调整必须接受未来独立样本检验。

**审计要求：** 对相同赛前球队信息，只改竞彩/皇冠赔率，独立模型胜率及重点排序必须逐字段保持不变。市场分歧说明可以变化，不能倒灌进入模型或排名。
