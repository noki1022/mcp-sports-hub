## 生产决策（明确）

- **独赢 / 让分：** 潜在收益可见，但尚未满足同一生产模型的回测、每名球员贡献可靠度、发布时间独立证明和产线概率重新校准。只能保留研究结果，不能产出假称 `WALK_FORWARD_PASS` 的参数文件。
- **竞彩/皇冠大小分：** 本次伤停特征导致总分 MAE、固定线 Brier 均恶化，**不启用伤停总分修正**。
- **五玩法真实盘口：** 无覆盖相同样本的逐时间戳 007 竞彩/皇冠历史盘口，不能宣称五玩法 ROI、EV 或真实让分盘概率已经通过。

**最终 P0 门槛：** 使用已冻结模型版本、可核验官方赛前发布时刻、经核对的球员 ID/球队/预计分钟、历史真实盘口和新的未见比赛；通过独立校准、Brier、LogLoss、稳定性评估后，再单独审批启用。此分支不改变 main 的概率输出和 PushPlus。
