# 数据源登记（V1）

## CBA

### ApiZero（优先候选）

- 用途：CBA 赛程、比分
- 免费额度：资料显示每天 20 次
- 状态：待用户提供登录/接口授权后验证
- 规则：只请求当天赛程和必要比赛结果，控制在额度内

### CBA 官方数据服务器

- 地址：data-server.cbaleague.com
- 用途：官方赛程、球员技术统计候选源
- 状态：待接口参数验证
- 规则：不绕过登录、验证码或访问限制

## NBA

### nba_api

- 用途：NBA 赛程、比赛结果、球员和球队统计
- 状态：作为公开数据源候选；需要运行环境具备网络访问
- 限制：不提供皇冠实际盘口

### StatsHawk

- 用途：当前已验证 NBA 赛程、战绩、roster/部分伤停
- 状态：可用
- 限制：当前不支持 CBA；未确认皇冠实时赔率

## 赔率

### The Odds API

- 用途：多公司赔率市场参考
- 状态：需要 API Key；免费额度/付费计划使用前必须确认
- 规则：必须记录 bookmaker、时间和赔率格式，不称为皇冠盘口，除非来源明确是皇冠

### betbetter-mcp

- 用途：模型胜率和公平赔率交叉验证
- 状态：候选辅助源
- 限制：不提供博彩公司实际挂牌赔率，不能代替皇冠盘口

## 当前默认策略

1. 赛程/赛果：StatsHawk（NBA）+ 经授权的 ApiZero 或官方源（CBA）。
2. 皇冠盘口：用户截图优先，保存为可下注快照。
3. 多公司共识：只有在获得合法 API 授权后才接入。
4. 模型输出：未经过滚动回测前只作参考，不生成可靠优势概率。
