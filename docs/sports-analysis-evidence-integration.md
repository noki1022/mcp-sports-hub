# 两项运动的分析证据整合

所有资料按“比赛身份—赛前可得时间—冻结答卷—原始赛果”连接。数据抓到不等于已核实；
字段缺失保留未知，不补造健康阵容、零伤停影响或虚构机构报价。

| 已有资料 | 当前作用 | 验证边界 |
|---|---|---|
| NBA历史比分、近期状态、交锋 | 独立基线、分差及总分分布 | 延续既有按时间训练；单独新增因素不能冒称已验证增益 |
| 足球近况、交锋、已核实伤停 | 进球分布基线；有界伤停修正 | 缺少身份、时点或可靠角色信息的伤停不量化 |
| 多机构让分/大小分、价格 | 同方向同尺度比较，机构分歧及模型差异 | 不把不同盘口的概率直接平均 |
| 连续快照，包括未变 | 同机构变化、速度、反转、停顿、上涨/下跌/未变比例、累计变化及方向一致程度 | 重复快照不是独立样本；盘口没变不能证明源站数据刚更新 |
| 足球真实亚洲盘 | 欧亚价格反演后，对独立进球差做有界修正 | 不凭让球变化直接提高总进球期望；机构相反调整时衰减影响 |
| 真实完场结果 | 重放冻结答卷、统计各玩法结果、准入训练 | 必须验证原文、比赛身份、时间、主客队及比分口径 |

本次修正：原来的中位数盘口不变可能掩盖机构向相反方向调整，现在显式识别分歧。
上涨后连续不变记录停顿时长，往返运动记录累计变化，不再只看初盘与终盘差值。
足球使用 v4，分歧衰减仅为保守有界规则，尚无实盘准确率提升结论。NBA新增轨迹维度
保留在每次分析和候选答卷中，未通过独立时间外验证前不自动改写生产概率。

NBA候选答卷新增现有模型的伤停处理状态、赛前状态摘要、分差/总分及方差证据。
足球修正已核实缺阵名单的状态筛选（OUT，不是并不存在的VERIFIED球员状态）。
历史候选不回写。训练数据新增带候选哈希与可得时点的分析特征，以及逐字段覆盖率；
未来比较加入盘口路径、近期状态、伤停特征前后的增益时，可以追溯每个输入。

权重研究仍按既有时间隔离门槛执行，数据不足不拟合复杂系数、不自动晋升。
每天累积独立赛事后依次做：基线对比、单因素消融、组合消融、独立测试集校准检查，
同时看命中率、Brier和log loss。已加入按比赛证据学习市场权重的研究器，按运动、联赛、玩法和版本分别拟合；
标准化与系数只使用训练集，验证集决定是否优于固定权重，测试集不参与选择。
历史样本或字段覆盖不足时不拟合。报告区分训练器已部署与真实系数已拟合，
更完整的伤停角色影响、球队结构参数与跨赛季晋升仍需另外验证。
归档仍在Release，Git只保存代码、政策及小型文档；原始快照、冻结预测和已验证复盘不覆盖。
